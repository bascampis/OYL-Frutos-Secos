# Plan de trabajo sugerido para Trello

Crea las listas: **Pendiente**, **En desarrollo**, **En revisión**, **Terminado**.

Tarjetas con título y criterio de aceptación verificable:

1. **ZIP 01: configuración Android** — abrir con Android Studio y sincronizar sin errores. Responsable asignable.
2. **ZIP 01: bienvenida / login / roles** — validar campos, probar cuentas ficticias, cerrar sesión.
3. **ZIP 02: entidades y DAOs Room** — almacenar clientes separados y poder relanzar la app.
4. **ZIP 02: registro y perfil** — rechazar campos incompletos y conservar sesión de demo.
5. **ZIP 03: catálogo, categorías y filtros** — filtros y búsqueda deben cambiar la lista.
6. **ZIP 03: detalle y carrito individual** — cantidades correctas y separación por cliente.
7. **ZIP 04: Spring Boot, API REST y Retrofit** — documentar endpoints, ejecutar servidor y probar conexión real.
8. **ZIP 04: pedidos e inventario** — validar stock y pedido en el servidor con transacción.
9. **ZIP 05: cámara y QR** — pedir permiso, escanear y manejar códigos inválidos.
10. **ZIP 05: mapa y ubicación** — mostrar punto de prueba real o aviso demostración y permisos.
11. **ZIP 06: notificaciones y animaciones** — funcionamiento y evidencias visuales.
12. **ZIP 06: tests, README, GitHub, evidencia y entrega** — verificar tareas, commits y APK.

Cada integrante debe mover solo tarjetas que trabajó y agregar enlaces a los commits verdaderos. La rúbrica habla de parejas; si su equipo tiene tres personas, consultarlo con el docente.
